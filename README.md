# 📈 Capstone Project: Predicting BSE Sensex 30 Closing Prices using Lagged Dow Jones Industrial Average (DJIA) Prices

## 📌 Overview
This project explores the relationship between **Dow Jones Industrial Average (DJIA)** prices and the **BSE Sensex 30** index in India.  
Using **lagged DJIA prices**, we build **Machine Learning** and **Deep Learning** models to predict **BSE Sensex closing prices**.

The project involves:
- 📊 **Data Collection** from financial market sources
- 🧹 **Data Preprocessing** (cleaning, transformation, feature engineering)
- 🤖 **Model Building** (ML & DL)
- 📈 **Model Evaluation & Comparison**

---

## 🎯 Objectives
- Investigate the correlation between **DJIA** and **BSE Sensex 30**.
- Use **lagged features** to predict **Sensex closing prices**.
- Compare **traditional ML models** and **Deep Learning** approaches.
- Identify the most accurate predictive approach.
